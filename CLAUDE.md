# CLI & API Learning Lab

Repository di sviluppo del laboratorio web (`src/`) e del tutor CLI (`tutor/`).

- Per **sviluppare** il laboratorio: `docs/SVILUPPO.md` (architettura in `docs/ARCHITETTURA.md`). `npm run check` esegue typecheck e test.
- Per **fare lezione** nel terminale reale: non lavorare da questa cartella; usa `cd tutor && claude` (le regole e i permessi del tutor stanno in `tutor/`).
- Lo stato del corso è `course/progress.json` (vista leggibile `course/progress.md`): non modificarlo durante lo sviluppo, tranne per i test dedicati.
